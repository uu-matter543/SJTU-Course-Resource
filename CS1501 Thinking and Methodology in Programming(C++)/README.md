附加说明：除了指系统库外，任何`<>`中的部分在实际编程中都要删去尖括号

`<>`仅表示实际编程中应替换为的内容类型，如下：

- `<codeblock>` 语句块
- `<constant>` 常量
- `<expression>` 表达式
- `<name>` 标识符
- `<operator>` 运算符
- `<param>` 参数
- `<type>` 类型名
- `<value>` 值（变量或常量或表达式）
- `<variable>` 变量名

另外：

- `<type>` 中类型为具体的数据类型时，表示该数据类型的一个变量
- `<entity i>` 在多个同类实体同时出现的语句中，`i`相等表示同一实体，`i`不相等表示不同实体
